# phit-website-entwuerfe

A collection of alternative physiotherapy-practice website designs. The existing directories contain distinct page/layout explorations and their CSS, scripts and media assets.

## Technology and local preview

HTML, CSS and browser JavaScript; existing assets and scripts retain their original notices.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000 and choose the existing entry page or design-variant subdirectory. A static preview does not require a database, application secret or paid service. Keep local caches and preview output out of Git.

## Implemented scope and limitations

This repository contains frontend website source. Do not infer a working appointment, payment or message-delivery backend from the presence of a visual control or contact section. External links, forms and third-party integrations were not submitted or activated during publication. The repository's existing site/deployment configuration is retained; this documentation branch does not enable an additional deployment.
